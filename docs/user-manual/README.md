# ShiftAware — User Manual

ShiftAware is a privacy-first shift planning tool for festival and event teams. Organizers build the schedule, run automated assignment, and manage the roster; team members log in, express preferences, and view their assignments — all without exposing real names in the system.

Start with [USER-MANUAL.md](./USER-MANUAL.md) for the full guide.

- **Organizers (admins):** read the [For organizers](#) section to set up events, configure shifts, manage the team, and finalize the schedule.
- **Volunteers (team members):** read the [For volunteers](#) section to log in, select your identity, submit preferences, and view your assignments.

> This manual covers the operator-facing UI. For developer and deployment documentation see the root `README.md` and `docs/`.
