### UI-1: Admin view toggle button jumps laterally

**Type:** Layout bug

**Symptom:** Switching between list view and calendar view on the admin schedule page causes the toggle button to jump laterally. The list view has no export button; when switching back to calendar view the export button re-appears and the toggle shifts position.

**Root cause:** The export button is only shown in calendar mode. No width reservation for the absent button in list mode.

**Proposed resolution:** Reserve space for the export button slot (e.g. `invisible` placeholder) or restructure the toolbar layout so the toggle position is independent of surrounding buttons.

**Files:** `app/admin/shifts/schedule/page.tsx` (toolbar area)

### UI-2: Admin schedule list view shows raw ShiftType enum

**Type:** Data display bug

**Symptom:** The list view card on the admin schedule page shows `STATIONARY` / `MOBILE_TEAM` etc. instead of the human-readable template name.

**Root cause:** The `Shift` interface in `schedule/page.tsx` does not include a `template` field, so line 843 falls back to `shift.type.replace("_", " ")`.

**Proposed resolution:** Add `template?: { id: string; name: string } | null` to the local `Shift` interface and update the API fetch to include the template relation. Replace line 843 with `shift.template?.name ?? shift.type.replace("_", " ")`.

**Files:** `app/admin/shifts/schedule/page.tsx:53-66, 843`

## Pre-existing TypeScript warnings (test tsconfig only)

The following test files use Vitest globals (`describe`, `it`, `expect`) without importing them. They run fine at runtime because Vitest injects globals, but `tsc` does not know about them. These are not production code errors.

- `tests/unit/DesirabilityBadge.test.tsx`
- `tests/unit/laneReorder.test.ts`
- `tests/unit/ProfileDetailCard.test.tsx`
- `tests/unit/services/assignments.service.test.ts`

**Resolution:** Add `"types": ["vitest/globals"]` to `tsconfig.json` compilerOptions, or add explicit `import { describe, it, expect } from "vitest"` to each file.
