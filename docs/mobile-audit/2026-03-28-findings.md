## Summary

### Top Issues

| # | State | Severity | Description |
|---|---|---|---|
| 1 | 2.3 Admin team | 🔴 | Empty state tells users to use a **header event dropdown** that is not shown on the 390px header — blocks understanding of how to load team data on mobile. |
| 2 | 2.2 / 2.7 Admin schedule | 🔴 | Same pattern: “Select an event from the header” while mobile header lacks an obvious event selector — admin workflows stall on small viewports. |
| 3 | 1.8 Swap modal | 🔴 | **Manual:** Swap tap on My Shifts does nothing; modal appears after switching to Full Schedule; **no indication which shift** was chosen. |
| 4 | 1.5 My Shifts | 🟡 | With zero assignments, shift detail / voting UI could not be validated; preference rows did not open a detail surface in the a11y tree. |
| 5 | 2.1 / 2.4 | 🟡 | Dense tab rows (Event Setup sub-tabs; team manage controls) — functional but small tap targets. |
| 6 | Member/Admin chrome | 🟡 | Identity is avatar-only in header on mobile; no textual alias (expected from `hidden md:flex` pattern). |

### Known Suspects from Code Review — Confirmed / Not Reproduced

| Area | Confirmed? | Notes |
|---|---|---|
| `w-80` panel + canvas flex row (state 1.7) | Not reproduced as broken | Detail presents as overlay/sheet; readable at 390px; canvas not squeezed to ~70px in this flow. |
| Desirability legend overflow (state 1.6) | Not reproduced | Three legend items fit without horizontal page scroll. |
| Header identity hidden md:flex (all states) | Confirmed (by design) | Logo + hamburger + avatar + actions only; alias not in header bar at 390px. |
| Swap modal on 390px (state 1.8) | **Confirmed broken (manual)** | Opens on view switch, not on tap; missing shift context in dialog. Automated run had no assignments. |

### Recommended Fixes (priority order)

1. **Expose event selection on mobile for admin (and any “select event from header” flows)** — e.g. persistent compact event picker in the admin/member header, or entry from sidebar, so Team Management and Shift Configuration are usable on phones.
2. **Fix swap on mobile:** Open the swap modal **immediately** from My Shifts when Request Swap is tapped; do not defer it until Full Schedule. Ensure the modal **names the source shift** (and time) so users know what they are swapping.
3. **Increase tap targets or allow wrapping** for admin sub-tab rows (Event Setup three tabs; shift configuration view toggles) where two or three controls compete on one line.
4. **Optional:** Surface current member alias in mobile header or sidebar footer (alongside avatar) for clarity without restoring full desktop header clutter.
5. **Document empty states** that reference UI elements hidden on `lg` — align copy with what mobile users actually see.
