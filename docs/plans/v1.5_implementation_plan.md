## Phase 1: Calendar Snap Feature

**Goal:** Templates snap to end of previous shift in same lane.

### Tasks

| Task | Owner | Delegation |
|------|-------|------------|
| 1.1 `calculateSnapPosition` utility | Ollama | ✅ Pure function |
| 1.2 `findNearestShiftEnd` utility | Ollama | ✅ Pure function |
| 1.3 Update DateDropZone with snap logic | Claude | ❌ Integration |
| 1.4 Add visual snap indicator | Claude | ❌ UI state |
| 1.5 Test snap behavior | Playwright | Agent |

### Ollama Task Specs

#### 1.1 calculateSnapPosition

```json
{
  "tool": "ollama_write_function",
  "name": "calculateSnapPosition",
  "description": "Given a drop time and list of existing shift end times, return the snapped time if within threshold, otherwise return original time.",
  "signature": "function calculateSnapPosition(dropTime: Date, shiftEndTimes: Date[], snapThresholdMinutes: number = 30): { snapped: boolean; time: Date }",
  "test_cases": [
    {
      "inputs": {
        "dropTime": "2026-07-15T10:00:00",
        "shiftEndTimes": ["2026-07-15T10:15:00"],
        "snapThresholdMinutes": 30
      },
      "expected": { "snapped": true, "time": "2026-07-15T10:15:00" }
    },
    {
      "inputs": {
        "dropTime": "2026-07-15T10:00:00",
        "shiftEndTimes": ["2026-07-15T12:00:00"],
        "snapThresholdMinutes": 30
      },
      "expected": { "snapped": false, "time": "2026-07-15T10:00:00" }
    },
    {
      "inputs": {
        "dropTime": "2026-07-15T10:00:00",
        "shiftEndTimes": [],
        "snapThresholdMinutes": 30
      },
      "expected": { "snapped": false, "time": "2026-07-15T10:00:00" }
    }
  ],
  "constraints": [
    "Use date-fns for date manipulation",
    "Return snapped time only if within threshold",
    "If multiple shifts end near drop time, snap to closest"
  ]
}
```

## Testing Strategy

### Playwright Test Scenarios

1. **Full Admin Workflow**
   - Create festival → Define team → Create templates → Schedule shifts (with snap) → Publish

2. **User Onboarding Flow**
   - Enter access code → Identify self → Select avatar → View calendar → Vote

3. **Export Flow**
   - Admin completes assignments → Export PDF → Verify format

1. Validation during generation (Ollama self-test)
2. Jest/Vitest test suite
