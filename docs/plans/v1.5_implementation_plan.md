## Phase 1.5: Lane-Based Calendar Architecture 🆕

**Goal:** Templates drop at correct position in correct lane with snap.

**Status:** Planning complete, implementation pending

**Detailed Plan:** `docs/plans/v1.5_calendar_architecture.md`

### Problem
Current CalendarView is a flat timeline. Drop zones only know the DATE, not:
- Which shift type (lane) was targeted
- What time within the day was targeted

### Solution: LaneCalendarView Component
New component with rows per shift type, time-aware drop zones.

  "description": "Given a drop time and list of existing shift end times, return the snapped time if within threshold, otherwise return original time.",

  "test_cases": [
    {

    },
    {
      "inputs": {

        "shiftEndTimes": ["2026-07-15T12:00:00"],
