### Task 1: Fix Node Content — Large Flow-Space Fonts + Descender Clipping

The approach: use big font sizes in flow-space so they're readable at zoom 0.1.
At zoom 0.1: `120px flow-space → 12px screen`. At zoom 1.0: text is big but
`overflow-hidden` clips naturally. ResizeObserver thresholds decide what content to show.

The descender clipping on "g", "p" etc. is caused by `items-baseline` alignment
in a container with `overflow-hidden` — descenders extend below the baseline and get
clipped. Fix with `leading-[1.15]` to include descender space in line-height.

Also fix the avatar display to show `avatarId` emoji instead of initials.

**Files:**
- Modify: `components/features/LaneCalendar/nodes/ShiftBlockNode.tsx`

- Names: `text-[140px] leading-[1.15] font-semibold` (14px on screen at zoom 0.1)
- Time/stars/row2: `text-[100px] leading-[1.15]` (10px on screen at zoom 0.1)
- Padding: `px-[16px] py-[8px]` (flow-space pixels for proper spacing at all zoom levels)
- Row 1: `items-center` instead of `items-baseline` to prevent descender clip
- Row gap: `gap-[10px]` in flow-space for visible spacing

import { type NodeProps, useViewport } from "@xyflow/react";

function LaneZoneNodeComponent({ data }: NodeProps) {
  const { color, width } = data as LaneZoneData;
  const { zoom } = useViewport();
  const tintColor = `${color}1A`;
  const borderWidth = Math.max(1, Math.ceil(1 / zoom));

  return (
    <div
      style={{
        width: `${width}px`,
        height: `${LANE_HEIGHT}px`,
        backgroundColor: tintColor,
        backgroundImage: "var(--lane-stripe)",
        borderBottom: `${borderWidth}px solid rgba(0,0,0,0.06)`,
      }}
      className="rounded-lg pointer-events-none"
    />
  );
}
