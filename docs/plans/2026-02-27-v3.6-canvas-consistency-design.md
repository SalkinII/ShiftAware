## Sprint Tasks (7 tasks)

### Task 1: Desirability Edit in ShiftPropertiesPanel

**Problem:** Sidebar shows desirability as a read-only `ProgressBar`. Only settable at creation time. The PUT body never includes `desirabilityScore`.

**Fix:**
- Add `desirabilityScore` state initialized from `shift.desirabilityScore` (default 3)
- Replace `ProgressBar` section with a clickable 1-5 `+` row in the Edit section
- Each `+` span: clicking it sets the score to that index (1-based)
- 3-tier colour: `text-blue-400` (score ≤2), `text-gray-400` (score=3), `text-amber-500` (score ≥4) — filled up to selected score, `text-gray-200` beyond
- Add `desirabilityScore` to PUT body in `handleSave`

**Files:**
- Modify: `components/features/LaneCalendar/sidebar/ShiftPropertiesPanel.tsx`

### Task 2: DesirabilityBadge — replace Star icon with `+` text

**Problem:** `DesirabilityBadge` uses Lucide `Star` icon and shows decimal score (`3.0`). Doesn't match `+` convention used everywhere else after the hotfix.

**Fix:**
- Remove `Star` import from lucide-react
- Replace `<Star className="w-3 h-3 fill-current" />` with `<span>{"+".repeat(score)}</span>`
- Replace decimal display `{score.toFixed(1)}` with integer `{score}`
- Keep 3-tier colour: `bg-blue-50 text-blue-700` (≤2), `bg-gray-100 text-gray-600` (=3), `bg-orange-50 text-orange-700` (≥4)
- Update title tooltip: `Desirability: ${score}/5 — ${score <= 2 ? "easy to get" : score >= 4 ? "hard to get" : "moderate"}`

**Files:**
- Modify: `components/ui/DesirabilityBadge.tsx`

### Task 7: Bug #5 — Lane Reorder with localStorage Persistence

**Problem:** Lanes display in fixed template order. No user control.

**Architecture:**
- Lane order state lives in `LaneCalendarCanvas` as `laneOrderOverride: Record<string, number>`
- On mount (when `eventId` is set), read `localStorage.getItem("shiftaware:laneOrder:${eventId}")` and parse as the override
- Apply override: after `deriveLanesFromTemplates`, remap each lane's `order` from the override map, then re-sort
- On reorder: compute new order map, set state, write to localStorage

**Fix — LaneLabelPanel:**
- Add `onReorder?: (laneId: string, direction: 'up' | 'down') => void` prop
- Each lane row: on hover, show up/down buttons (small, `pointer-events-auto`)
- First lane: no up button; last lane (excluding Unassigned): no down button
- Button style: `text-gray-400 hover:text-gray-700`, tiny (e.g. `text-xs` arrows `▲`/`▼` or chevron icons)

**Fix — LaneCalendarCanvas:**
- Add `laneOrderOverride` state: `Record<string, number>`
- `useEffect` on `eventId`: load from localStorage, set state
- `handleReorder(laneId, direction)` function:
  - Find current sorted lanes
  - Swap the lane with its neighbour in the given direction
  - Rebuild order map (index → each lane.id)
  - Update state + localStorage
- Pass `onReorder={handleReorder}` to `LaneLabelPanel`
- Apply override when deriving display lanes

**Files:**
- Modify: `components/features/LaneCalendar/panels/LaneLabelPanel.tsx`
- Modify: `components/features/LaneCalendar/LaneCalendarCanvas.tsx`
