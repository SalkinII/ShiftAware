## Core Workflow Definition

This document defines the **only supported workflow** for ShiftAware v1.5. All features must serve this workflow; components that don't will be removed or deferred.

### Workflow Stages

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  STAGE 1: ADMIN SETUP                                                       │
│  ┌──────────────────┐    ┌──────────────────┐    ┌──────────────────┐      │
│  │  Define Festival │ →  │  Define Team     │ →  │  Define Templates│      │
│  │  (dates, config) │    │  (members, roles)│    │  (shift patterns)│      │
│  └──────────────────┘    └──────────────────┘    └──────────────────┘      │
└─────────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─────────────────────────────────────────────────────────────────────────────┐
│  STAGE 2: SHIFT PLANNING                                                    │
│  ┌──────────────────────────────────────────────────────────────────┐      │
│  │  Calendar View: Drag-drop templates onto timeline               │      │
│  │  • Templates snap to end of previous shift (seamless succession) │      │
│  │  • Visual time display on hover/drag                            │      │
│  │  • Lane-based organization by shift type                         │      │
│  └──────────────────────────────────────────────────────────────────┘      │
└─────────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─────────────────────────────────────────────────────────────────────────────┐
│  STAGE 3: PUBLISH TO USERS                                                  │
│  ┌──────────────────┐    ┌──────────────────┐                              │
│  │  Generate user   │ →  │  Publish shift   │                              │
│  │  access codes    │    │  plan to users   │                              │
│  └──────────────────┘    └──────────────────┘                              │
└─────────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─────────────────────────────────────────────────────────────────────────────┐
│  STAGE 4: USER ONBOARDING & PREFERENCES                                     │
│  ┌──────────────────┐    ┌──────────────────┐    ┌──────────────────┐      │
│  │  User enters     │ →  │  User identifies │ →  │  User votes on   │      │
│  │  access code     │    │  self + avatar   │    │  shift wishes    │      │
│  └──────────────────┘    └──────────────────┘    └──────────────────┘      │
└─────────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─────────────────────────────────────────────────────────────────────────────┐
│  STAGE 5: ASSIGNMENT                                                        │
│  ┌──────────────────┐    ┌──────────────────┐    ┌──────────────────┐      │
│  │  Admin runs      │ →  │  Publish         │ →  │  Admin makes     │      │
│  │  algorithm       │    │  assignments     │    │  manual changes  │      │
│  └──────────────────┘    └──────────────────┘    └──────────────────┘      │
└─────────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─────────────────────────────────────────────────────────────────────────────┐
│  STAGE 6: EXPORT                                                            │
│  ┌──────────────────────────────────────────────────────────────────┐      │
│  │  Export to pretty PDF (user-friendly format)                      │      │
│  └──────────────────────────────────────────────────────────────────┘      │
└─────────────────────────────────────────────────────────────────────────────┘
```

## Critical Missing Features (Priority Order)

### P0: Template Snapping (Stage 2)
**Problem:** Templates can be placed anywhere; no snap-to-end behavior.
**Solution:** When dragging template near shift end, snap to exact end time.
**Ollama delegatable:** Yes - pure geometry/time calculation function.

### P1: User Access Codes (Stage 3)
**Problem:** Single login system, not festival-scoped.
**Solution:** Generate unique codes per festival, users enter code to access specific festival.
**Ollama delegatable:** Partial - code generation yes, auth flow integration no.

### P1: Publish Workflow (Stage 3)
**Problem:** No staged publishing (draft → published).
**Solution:** Add `status` field to shifts/events, publish button commits.
**Ollama delegatable:** No - spans multiple files/concerns.

### P2: User Onboarding Flow (Stage 4)
**Problem:** No guided flow for new users.
**Solution:** First-time user sees identification modal before accessing app.
**Ollama delegatable:** Partial - modal component yes, state management no.

### P3: Pretty PDF Export (Stage 6)
**Problem:** Current export is functional but not pretty.
**Solution:** Redesign PDF template with better formatting.
**Ollama delegatable:** Yes - PDF template generation is isolated.
