### Bug 1: DateDropZone Missing `style` Prop

**File:** `components/features/Calendar/CalendarView.tsx:874`

**Error:**
```
Property 'style' does not exist on type 'IntrinsicAttributes & DateDropZoneProps'.
```

**Root Cause:**
`CalendarView.tsx` passes a `style` prop to `<DateDropZone>`, but the `DateDropZoneProps` interface doesn't include `style`.

**Current Props Interface** (`DateDropZone.tsx:7-12`):
```typescript
interface DateDropZoneProps {
  date: Date;
  className?: string;
  children?: React.ReactNode;
  as?: "div" | "th" | "td";
}
```

**Fix Options:**

| Option | Approach | Pros | Cons |
|--------|----------|------|------|
| A | Add `style?: React.CSSProperties` to `DateDropZoneProps` | Simple, backward compatible | Allows arbitrary styling |
| B | Use className + Tailwind arbitrary values | Consistent with project patterns | May need complex class syntax |
| C | Add specific positioning props (`left`, `width`, `height`) | Type-safe | More verbose API |

**Recommended:** Option A - Add `style` prop to interface

**Files to Modify:**
- `components/features/Calendar/DateDropZone.tsx` - Add `style` to props interface and spread to element
