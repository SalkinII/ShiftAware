## Issue Categories

### P0: Critical Bugs

| Issue | Location | Description | Status |
|-------|----------|-------------|--------|
| Hydration error | `/login` | Investigated - Suspense setup is correct, may be browser/extension issue | ✅ Verified |
| Delete button broken | Team Manage | Was "Delete" icon but did soft-delete, no reactivate path | ✅ Fixed |

### P1: Non-Functional UI Elements (Remove or Implement)

| Element | Location | Action | Status |
|---------|----------|--------|--------|
| Notifications button | Header | Removed (showed "coming soon" toast) | ✅ Done |
| Settings button | Header | Removed (had no handler) | ✅ Done |
| Deactivate button | Team Manage | Fixed - UserX icon, amber color, + reactivate button | ✅ Done |

### P2: View Separation (Admin vs User)

| Issue | Current State | Desired State |
|-------|---------------|---------------|
| "Manage Team" in user view | Visible to users | Should be admin-only |
| "Review Gaps" | Mixed view | Useful for users (see unfilled slots), but primarily admin |
| Shift Templates | Available in user calendar | Admin-only tool for populating calendar |

### P3: Event/Festival Setup Workflow

**Current Problem:** No way to create events from scratch. "No events found" with no creation flow.

**Desired Workflow:**
1. Create new event (name, dates, buffer days)
2. Define core days vs buffer days
3. Assign/create shift templates for this event
4. Populate calendar with template bundles
5. Calendar always anchors to event's core dates

### P4: Template & Shift UX

| Issue | Current | Desired |
|-------|---------|---------|
| Duration input | Minutes (e.g., 359) | Hours or HH:MM format |
| Start time required | Yes | Optional - applied when dropped on calendar |
| End time | Calculated from duration | Editable, auto-updates duration |
| Template drag-drop | Works | Should snap into place, successive shifts |

### P5: Heatmap/Allocation View

| Issue | Description |
|-------|-------------|
| Too spaced out | Condense layout, consider screenshot-friendly |
| All yellow | Misleading - should use traffic light colors |
| Click action unclear | Clicking should assign person to shift |

**Proposed Color Scheme:**
- **Green:** Can be assigned (no conflicts)
- **Yellow:** Potential conflict (rule-based warning)
- **Red:** Cannot assign (already has shift, not eligible, all-male shift rule)

### P6: Team Member Attributes

| Issue | Current | Desired |
|-------|---------|---------|
| Gender options | M_NB (unclear) | Flexible: Male, FLINTA, NB, custom |
| Attribute system | Rigid/hardcoded | Extensible, user-definable attributes |
| Delete members | Only deactivate | Allow true deletion (with confirmation) |

### P7: Calendar UX

| Issue | Description |
|-------|-------------|
| Date header | Should be sticky (hover with scroll) |
| Default view | Should anchor to event core dates, not today |
| Navigation | Too many clicks to reach festival dates |

### P8: Algorithm/Allocation

| Issue | Description |
|-------|-------------|
| Black box algo | User doesn't understand what it does |
| Dashboard display | Algorithm scores shown but not explained |
| Manual override | Need ability to manually assign + see eligibility |

**Desired Workflow:**
1. Auto-assignment runs first (optional)
2. Admin reviews assignments
3. Can remove specific people from shifts
4. See who is eligible for empty slots
5. Manually assign from eligible list
6. All changes logged

### P9: Publish Workflow

**Current:** "Publish workflow - coming soon"

**Desired Flow:**
1. Admin sets up event + shifts
2. **Publish #1:** Opens voting to users
3. Users log preferences
4. Admin runs allocation (auto or manual)
5. **Publish #2:** Publishes final schedule to users
6. Calendar view shows published schedule (centered on core dates)
7. All flow logged for audit

### P10: Small UI Fixes

| Item | Location | Fix |
|------|----------|-----|
| Star emoji | Login page | Change to sloth emoji |
| "Starlight Meadow Festival" | Dashboard | Should come from event config, not hardcoded |

## Implementation Priority

### Phase 1: Critical Fixes
1. Fix hydration error on login page
2. Remove non-functional Notifications/Settings buttons
3. Fix Delete/Deactivate buttons in Team Manage

### Phase 2: View Separation
1. Hide admin-only features from user view
2. Implement proper RBAC checks on UI elements

### Phase 3: Event Setup
1. Create "New Event" flow in Festival Setup
2. Connect events to calendar anchoring
3. Template bundles per event

### Phase 4: UX Polish
1. Duration input as hours/HH:MM
2. Sticky date header in calendar
3. Heatmap color scheme (green/yellow/red)
4. Condense heatmap layout

### Phase 5: Advanced Features
1. Extensible member attributes
2. Publish workflow (2-stage)
3. Algorithm transparency + manual override
