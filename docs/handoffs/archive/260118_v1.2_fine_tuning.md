## Issues to Fix

### Issue 1: Incorrect Password Test Logic

**File:** `tests/e2e/auth.spec.ts:32`

**Problem:** Test calls `loginPage.login("wrong-password")` but `LoginPage.login()` throws an error when login fails. The test expects to check for error message visibility, but the throw happens first.

**Fix:** Wrap login call in try-catch, then verify error message is visible.

```typescript
// Current (broken)
await loginPage.login("wrong-password");
// ... check for error

// Should be
try {
  await loginPage.login("wrong-password");
  throw new Error("Should have failed");
} catch (e) {
  // Expected - now verify error message
  await expect(loginPage.errorMessage.first()).toBeVisible();
}
```
